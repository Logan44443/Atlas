# Four Winds

A browser-based multiplayer open-world game about elemental bending (Water, Earth, Fire, Air).
Players open a link and play: no installs.

- Design: [docs/DESIGN.md](docs/DESIGN.md)
- Engineering notes: [CLAUDE.md](CLAUDE.md)

## Phase details

Each phase has a goal, a list of what it delivers, and a "done when" test. Finished phases also say what was
actually built and how it was checked. Design reference for every item: [docs/DESIGN.md](docs/DESIGN.md).

### Phase 1: Foundations ✅ Done

**Goal:** a good-looking, fast 3D world in the browser that every later phase builds on.

**What it delivers**
- Project setup: TypeScript, Vite, three.js `WebGPURenderer` with automatic WebGL2 fallback for older browsers.
- Stylized, painterly look: toon shading with a 4-step light ramp, vertex-coloured terrain (sand, grass, dirt, rock, snow), bloom on glowing things.
- Procedural terrain from a seed (continents, hills, mountains, coastlines) so the whole world is a pure function of `data/world.json`.
- Sky with sun, moon and stars; a day/night cycle (24 real minutes per day) with moon phases, fog and lighting that change with the hour.
- Wind-animated grass and scattered trees, rocks and bushes.
- Low / Medium / High quality presets, auto-picked from the device and stepped down if FPS drops.
- Debug overlay (F3): FPS, draw calls, triangles, renderer, quality, clock, position, plus time-of-day controls.

**Done when:** the world renders without errors on WebGPU and WebGL2, all three presets work, and the overlay shows live stats.
**Built and checked:** yes, verified in headless Chromium (WebGL2) with screenshots at noon, dusk and night.

### Phase 2: Chunk streaming ✅ Done

**Goal:** a 4 km world that loads only what's near you, so it opens fast and runs on laptops and phones.

**What it delivers**
- A 64 × 64 grid of 64 m chunks generated by `npm run world`: heights plus a JSON file per chunk (props, NPC spawns, resource nodes, base plots), and a `manifest.json` with a version hash per chunk.
- Load rings around the player: near (full detail, physics), mid (simpler mesh), far (low-poly), fog beyond.
- Prefetching ahead in the direction of travel, unloading well behind, mesh building in background workers.
- Caching in three layers: in-memory LRU, a Service Worker that keeps chunks between visits and only re-downloads changed ones, then the network/CDN.
- Chunk-state map (F4 / M) showing which chunks are near, mid, far, building, fetching or cached.

**Done when:** you can travel across the world without hitches, and a reload serves chunks from cache.
**Built and checked:** yes; a reload test served 212 chunks from the Service Worker cache with 0 network fetches.

### Phase 3: Character ✅ Done

**Goal:** moving around feels good before any fighting exists.

**What it delivers**
- Third-person character controller on Rapier physics: walk, sprint, jump (with coyote time and jump buffering), dodge roll, swimming, block stance.
- Over-the-shoulder camera that avoids clipping into terrain, with mouse look and zoom.
- A procedural placeholder avatar with run, jump, swim, dodge and cast animations, plus a floating nameplate.
- Settings menu (Esc or gear button): rebind every control (two keys per action, conflict warnings, reset), edit display name, mouse sensitivity, invert Y, graphics quality.
- Free camera for debugging (F2).

**Done when:** walking, jumping, dodging and swimming work on real terrain, and rebinding and renaming save between visits.
**Built and checked:** yes, a headless test walks, sprints, jumps, dodges, renames and rebinds a key.

### Phase 4: Bending v1 ✅ Done

**Goal:** the core of the game: third-person bending combat that is fun against training targets.

**What it delivers**
- All four elements with 6 abilities each (Basic, Heavy, Control, Defense, Mobility, Ultimate), every number in `data/abilities/*.json`.
  - Water: water whip, ice spikes, wave surf, ice wall, freeze, tidal surge.
  - Earth: rock throw, boulder smash, earth glide, stone armor, quake root, earthquake ring.
  - Fire: fire jab combo, fire blast, jet dash, fire shield, flame ring, inferno breath.
  - Air: air slice, air cannon, air scooter, air bubble, vortex pull, tornado.
- Chi as the resource (fast regen out of combat), cooldowns, combos.
- Stance: hold to block, perfect-timed blocks counter (reflect projectiles, stagger melee), dodge with invulnerability frames.
- Status effects: burn, slow, root, stagger. Shields that block or reflect projectiles.
- Element rules: Water stronger at night, near water and under a full moon; Fire stronger by day; Earth must be grounded and is stronger on rock; soft ~10% matchups.
- Target assist toward whatever is near the crosshair; Tab cycles targets.
- Particle VFX with bloom, combat HUD (health, chi, ability bar with cooldowns, target frame, floating damage numbers).
- Training dummies and a sparring dummy that attacks with a visible wind-up so you can practise counters.

**Done when:** every ability of every element works against the dummies, and perfect blocks counter.
**Built and checked:** yes; a headless test fires all 24 abilities at the dummies and lands perfect-block counters.

### Phase 5: Multiplayer ✅ Done

**Goal:** many people in the same world, with the server as the referee so nobody can cheat combat.

**What it delivers**
- Node + Colyseus game server. Each room is a world shard of up to 80 players; a full shard opens a new one.
- Join flow: auto-assign to a shard (or pick one with `?shard=`), the server sends your spawn point and the world clock.
- Server-authoritative combat: the client only asks to cast; the server runs the same combat rules (`shared/sim`) and decides every hit, block, status and death.
- Client-side prediction for your own movement only; the server checks speed, height and bounds and snaps you back if something's wrong.
- Interest management: each client is sent only what's within about 3 chunks.
- Other players drawn smoothly about 0.1 s behind (interpolation), with their casts and animations.
- The same day/night clock for everyone. Offline fallback if no server answers.

**Done when:** two browsers on one shard see each other move, hits land the same for both, and a speed hack gets corrected.
**Built and checked:** yes; `scripts/net-test.mjs` runs two browsers and passes all of those checks.

### Phase 6: Characters and factions 🔨 In progress

**Goal:** you are someone in the world: a named character, with an element and a faction, living somewhere.

**What it delivers**
- Accounts: play instantly as a guest, then turn that into a real account (username + password) without losing characters. Saved in PostgreSQL.
- Title screen: up to 4 character slots. Creating one means choosing a name, a permanent element, and one of six factions.
- Six factions on two sides, each with a hub town, colours, emblem and perk:
  - Order: Sentinel Corps (police fort), Lantern Order (monastery), Free Isles League (harbor).
  - Outlaw: Red Fang Triad (gang den), Ash Syndicate (smugglers' wharf), Hollow Moon Cult (sanctum).
- NPC members in every hub: vendor, trainer, envoy (quest giver), gate guards and patrols. Press G to talk; patrols attack players from the rival side near their town.
- Zones: hubs are safe (no PvP), three contested shrines always allow PvP between sides, the Wilds need both players to raise a PvP flag (P, from level 10).
- Anti-griefing basics: 10 s spawn protection, much higher-level players deal reduced damage.
- Characters spawn at their faction hub, respawn there, and come back where they logged out.

**Done when:** a new player can create a character through the UI, spawn in their hub, talk to NPCs, be safe in hubs, fight rivals at shrines, and rejoin where they left.
**Status:** built and pushed; 9 of 10 browser checks in `scripts/phase6-test.mjs` pass. Remaining: PvP at contested shrines isn't dealing damage yet.

### Phase 7: Progression · Planned

**Goal:** a reason to keep playing: getting stronger over time.

**What it will deliver**
- XP from NPC kills, quests, PvP kills (scaled by level difference), territory captures, taming, building milestones and discovering landmarks.
- Bending Level 1–50: each level gives +2% bending power and a mastery point.
- Mastery trees: three branches per element (for Fire: Precision, Inferno, Breath), respec for gold.
- Parties of up to 4 same-side players with shared XP within 50 m and party markers.
- Party combat combos, for example Water + Fire making a blinding steam cloud.
- The rest of anti-griefing: no XP from players 10+ levels below you, diminishing XP for repeat kills.
- Faction perks that depend on XP and bounties start working (Red Fang PvP XP, Sentinel bounty damage).

**Done when:** killing things and doing tasks levels you up, mastery points change your abilities, and a party shares XP and can pull off a combo.

### Phase 8: Special Arts · Planned

**Goal:** advanced bending that players work toward and that changes how they fight.

**What it will deliver**
- Master NPCs hidden around the world, each with a mastery quest.
- The arts, one at a time, each with its unlock and its limit:
  - Healing (Water, Lv 15): heal allies and cleanse burns; weaker while fighting players.
  - Metalbending (Earth, Lv 20): pull armored enemies, cable grapple; metal only.
  - Lightning (Fire, Lv 20): 1.5 s charge, then an instant strike; can be redirected by a well-timed block.
  - Lavabending (Earth, Lv 35): lava pools that cool into rock walls.
  - Combustion (Fire, Lv 35): telegraphed long-range explosive shot.
  - Flight (Air): glider at Lv 10, true flight at Lv 40; no attacks while flying.
  - Bloodbending (Water, Lv 40): night only; Order players lose faction rank for learning it, Hollow Moon Cult doesn't.
  - Spirit Projection (any, Lv 45): scout as a spirit while your body is vulnerable.

**Done when:** each art can be unlocked through its quest and works within its stated limits.

### Phase 9: Building · Planned

**Goal:** leave a mark on the world: camps, crafted materials and crew bases.

**What it will deliver**
- Camps: a campfire, tent and chest anywhere in the Wilds (not near hubs); a personal respawn point that burns down after 24 h offline.
- Bending crafting: two players channel elements together (Water + Earth = mud, Fire + Water = steam, Fire + Earth = glass, Air + Fire = forge, and more), or one element on a world source (Fire on sand = glass). Results are materials or placed structures. Recipes in `data/crafting/combos.json`.
- Crew bases on claimed plots: snap-grid walls, gates, towers, workshop, pet stable, element shrine; tiers wood → stone → metal → spirit-warded.
- Raid windows: rival factions can only raid during scheduled windows, so bases aren't wiped while owners sleep.

**Done when:** a player can set up a camp, two players can craft a combo material, and a crew can build a base that rivals can raid only in its window.

### Phase 10: Pets · Planned

**Goal:** companions and mounts, up to legendary creatures won through big fights.

**What it will deliver**
- Common pets (fox-hound, shell turtle, glider lemur): feed them in the wild and win a short trust minigame.
- Rare pets (armored rhino mount, polar-wolf, eel-hound): a questline plus a mini-boss.
- Legendary pets (Sun Dragon, Cloud Bison, Tide Serpent, Burrow Titan): a multi-phase world boss for 4–12 players, then a small chance at a hard solo Bond Trial; must match your element.
- Pets level with you, need care, one active at a time, the rest in your base stable.

**Done when:** you can tame a common pet, earn a rare one, and a group can beat a legendary boss with a chance at the Bond Trial.

### Phase 11: Territory wars, crews, polish, deployment · Planned

**Goal:** the full game, online for real players.

**What it will deliver**
- Territory wars on a schedule: factions capture shrines and outposts for buffs and resource income.
- Crews (guilds) of up to 30 with a shared base, bank and rank; one hired NPC companion.
- Polish: real art and animation in place of the primitive placeholders, sound, touch controls for phones, gamepad.
- Deployment: client and world chunks on a CDN, game servers on a VPS or Fly.io, PostgreSQL hosting, monitoring. (Paid services wait for the owner's approval.)

**Done when:** strangers can open a link, play, and the servers stay up and observable.

## Run it

```bash
npm install
npm run dev:all   # game server on :2567 + client on http://localhost:5173
```

`npm run dev` runs the client alone; without a server it plays offline. PostgreSQL is optional in
development (the server falls back to memory); set `DATABASE_URL` in production.

## Controls

WASD move, Shift sprint, Space jump, V dodge, left click basic attack, Q/E/R/F/X abilities, hold right click
to block (time it to counter), Tab target, G talk, P PvP flag, Esc settings. All rebindable in Settings.
